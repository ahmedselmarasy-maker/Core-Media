إصلاح ظهور مشاريع الأقسام — Core Media

ارفع script.js فقط إلى جذر مستودع Core-Media على GitHub، في نفس مكان index.html.

الخطوات:
1) افتح المشروع على GitHub ثم Add file > Upload files.
2) ارفع script.js الموجود مع هذا الملف (لا ترفع ZIP نفسه).
3) اختر Commit directly to main واضغط Commit changes.
4) انتظر تحديث نشر Vercel ثم افتح الموقع واضغط Ctrl + F5 لتحديث الملفات المخزنة بالمتصفح.

ماذا عالج التحديث؟
- استرجاع المشاريع الأصلية الموجودة في index.html عند غياب/فشل بيانات Supabase أو كون الكاش المحلي فارغًا.
- إصلاح التصنيف الموروث لبيانات المشاريع المصرية القديمة إذا كانت جميعها مخزنة بدون تصنيف فعلي.
- استمرار أولوية بيانات Supabase حين تحتوي على مشاريع مصنفة بصورة سليمة.

الموقع يحتوي أصلًا على هذه المشاريع ضمن ملفات HTML:
مطاعم 3، كافيهات 2، ميديكال 3، مشاريع أخرى 5 (منها 3 مشروعات سعودية قديمة)، تعليم 0.
قسم التعليم سيظل فارغًا حتى تضيف مشاريع له من لوحة التحكم.

مهم: إصلاح ظهور بطاقة المشروع لا يعالج نقص الصور أو الفيديوهات الفعلية المرتبطة بـ Git LFS.
ومهم أيضًا: إذا كانت مشاريعك موجودة في Supabase لكنها غير مصنفة، افتح لوحة التحكم وراجع تصنيف كل مشروع.
