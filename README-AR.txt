إصلاح اختفاء كروت المشاريع داخل الأقسام — Core Media

ارفع ملف gateway.css فقط إلى جذر مستودع Core-Media على GitHub
(نفس مكان index.html وscript.js)، واستبدل النسخة الموجودة.
احفظ عبر Commit directly to main ثم انتظر اكتمال النشر على Vercel.
بعد النشر افتح الموقع واضغط Ctrl+Shift+R، ثم افتح قسم الميديكال.

الإصلاح يضبط ظهور الكروت بعد تحميلها ديناميكيًا، بدون تعديل
المشاريع أو بيانات Supabase أو ملفات الصور والفيديو.
