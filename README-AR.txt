تحديث Core Media - إدارة الأقسام من لوحة التحكم

ارفع الملفات التالية إلى جذر مستودع GitHub بنفس أسماء الملفات:
index.html
admin.html
script.js
admin.js
gateway.css
admin.css

لا ترفع ملف ZIP نفسه. لا تحذف ملفات الوسائط أو اللوجو أو ملفات Supabase الحالية.

بعد النشر على Vercel:
1. افتح admin.html وسجّل دخول الأدمن.
2. افتح «إدارة الأقسام والمشاريع» لضبط عنوان شاشة الاختيار وألوانها وأسماء الأقسام والأيقونات والصور والظهور والترتيب.
3. من «إضافة المشاريع القديمة إلى الأقسام» اختر القسم، وعلّم على المشاريع التي تريد عرضها، ثم اضغط «حفظ مشاريع القسم».
4. يمكنك جعل المشروع يظهر في أكثر من قسم بدون إعادة رفع ملفاته.
5. من «الصفحة الرئيسية» يمكن تعديل نصوص الهيرو ورسالة الكارت، ومن «من نحن» و«التواصل والإعدادات» يمكن تغيير محتواهما.

تم حذف عبارة Core Media Campaign Hub وعبارة «استراتيجية • محتوى • تصميم • إعلام» من كارت الصورة الرئيسية.
الحفظ المباشر للزوار يعتمد على صلاحيات Supabase للجداول الحالية، وبخاصة cm_site_settings وcm_brands.
