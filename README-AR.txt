Core Media — مصدر البيانات والحذف الآمن

- Supabase هي المصدر الأساسي للمشروعات وإعدادات الموقع.
- index.html لا يحتوي على كتالوج مشروعات قديم، ولا يُستخدم لإعادة تعبئة قاعدة البيانات.
- نتيجة قاعدة البيانات الفارغة حالة صحيحة؛ لن يعيد الموقع أو لوحة التحكم المشاريع المحذوفة تلقائيًا.
- تُحدّث النسخة المحلية الاحتياطية بعد نجاح القراءة أو الكتابة فقط، وتُستخدم للعرض المؤقت عند تعطل الاتصال ولا تُرفع إلى قاعدة البيانات تلقائيًا.
- حذف مشروع أو عنصر وسائط يحاول حذف ملفات Supabase Storage غير المستخدمة فقط، بعد التحقق من جميع مراجع المشروعات وإعدادات الموقع.
- زر «فحص الملفات غير المستخدمة في التخزين» يعرض عدد الملفات وحجمها ويطلب تأكيدًا قبل الحذف النهائي.
- لا تُحذف ملفات التخزين عبر SQL DELETE من storage.objects؛ يجب استخدام Supabase Storage API.

النشر: ارفع ملفات المشروع المعدلة إلى جذر مستودع Core-Media على GitHub ثم انتظر اكتمال نشر Vercel.
